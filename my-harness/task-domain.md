# 실습할 내 업무 1개 정하기

선택 기준 (3개 모두 만족해야 함)
1. 최근 3개월 안에 2번 이상 해본 일
2. 매번 결과가 조금씩 달라서 불만인 일
3. 중간에 파일·문서가 남는 일

## 후보 (해당하는 것에 체크하고 1개만 남기기)
| 후보 | 3개월 내 2회+ | 결과 편차 불만 | 산출물 남음 |
|------|:---:|:---:|:---:|
| PRD → 와이어프레임 뽑아내기 (Figma) | ☐ | ☐ | ☐ |
| 디자인 QA (시안 vs 구현 비교) | ☐ | ☐ | ☐ |
| 개발 핸드오프 문서 작성 | ☐ | ☐ | ☐ |
| 랜딩페이지 기획 | ☐ | ☐ | ☐ |
| 배너 제작 | ☐ | ☐ | ☐ |

## 최종 선택
- 업무: **PRD → 와이어프레임 뽑아내기** (공지 예시 · 위 prd.md / design.md와 바로 연결됨)
- 입력물: `prd.md`, `design.md`
- 기대 산출물: 화면 목록 5개의 Figma 와이어프레임
- 지난 결과물(있다면): `refs/` 폴더에 1~2개 넣어두기

> 다른 업무를 고르시면 이 섹션만 바꿔주세요.
