# PRD — 틱택토 (Tic-Tac-Toe) 웹 게임

## 1. 한 줄 정의
틱택토는 **잠깐 쉬는 시간이 생긴 사람**이 **친구나 컴퓨터와 한 판 승부**를 **설치 없이 브라우저에서 30초 만에** 하는 서비스다.

## 2. 주요 사용자
- **페르소나**: 김지은(29), 스타트업 마케터. 회의 사이 5~10분씩 짬이 남는다.
- **현재 불편함**: 모바일 게임은 설치·광고·회원가입이 번거롭고, 한 판이 너무 길다.
  옆자리 동료와 가볍게 내기할 도구도 마땅치 않다.

## 3. 사용자 시나리오 ⭐
**A. 컴퓨터와 한 판**
1. 링크를 열면 바로 게임 보드가 보인다
2. "컴퓨터와 하기"와 난이도(쉬움/어려움)를 고른다
3. 칸을 눌러 X를 두고, 컴퓨터가 O를 둔다
4. 승/패/무 결과를 보고 "다시 하기"를 누른다

**B. 옆 사람과 한 기기에서**
1. "같이 하기(2인)"를 고른다
2. X와 O가 번갈아 칸을 누른다 (현재 차례가 상단에 표시)
3. 한 줄이 완성되면 승리 줄이 강조된다
4. 누적 스코어를 확인하고 다음 판을 시작한다

**C. 기록 확인**
1. 홈에서 "내 기록"을 누른다
2. 오늘/전체 승·패·무 수를 본다
3. "기록 초기화"로 리셋한다

## 4. 화면 목록
1. 홈 (모드 선택)
2. 게임 보드
3. 결과 모달
4. 내 기록
5. 설정 (난이도·사운드·테마)

## 5. 가치 기준
- **지킬 것**: 링크 진입 후 첫 수까지 3초 이내 / 회원가입 없이 전부 사용 가능
- **안 할 것**: 게임 중 광고 노출 금지 / 한 판 흐름을 끊는 팝업 금지
