# 용어집 (Glossary)

문서·피그마·코드 모두 이 단어만 씁니다. 코드 이름은 오른쪽 칸을 그대로 사용해요.

| 용어 | 뜻 | 코드 이름 |
|------|----|-----------|
| 게임 | 빈 보드에서 시작해 결과가 날 때까지의 한 판 | `Game` |
| 보드 | 3×3, 총 9개의 칸 | `board` |
| 칸 | 보드의 한 자리. 0~8 번호로 부른다 | `cell` |
| 마크 | 칸에 두는 표시. X 또는 O | `Mark` (`"X"` \| `"O"`) |
| 플레이어 | 마크 하나를 맡아 수를 두는 사람 또는 컴퓨터 | `player` |
| 컴퓨터 | 게임 규칙에 따라 스스로 수를 고르는 플레이어 | `Computer` |
| 난이도 | 컴퓨터의 수준. 쉬움 / 어려움 | `Difficulty` (`"easy"` \| `"hard"`) |
| 차례 | 지금 수를 둘 수 있는 플레이어의 마크 | `turn` |
| 수 | 차례인 플레이어가 빈 칸에 마크를 두는 행동 | `placeMark()` |
| 승리 줄 | 같은 마크 3개가 놓인 가로·세로·대각선 한 줄 | `winningLine` |
| 결과 | 게임이 끝난 방식. X 승리 / O 승리 / 무승부 | `result` (`"X"` \| `"O"` \| `"draw"`) |
| 스코어 | 여러 게임의 X 승리·O 승리·무승부 누적 수 | `Score` |
