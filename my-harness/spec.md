# 스펙 (요구사항)

## ① 게임 상태
```
진행 중(X 차례) ⇄ 진행 중(O 차례)
진행 중 → X 승리 | O 승리 | 무승부   (결과가 나면 끝, 되돌아가지 않음)
```

## ② 비즈니스 규칙 (불변식)
| ID | 규칙 | 출처 |
|----|------|------|
| R1 | 새 게임의 첫 차례는 항상 X다 | DS-1 2 |
| R2 | 빈 칸에만 마크를 둘 수 있다 | DS-2, US-2 |
| R3 | 수를 두면 차례가 상대에게 넘어간다. 거절된 수는 차례를 바꾸지 않는다 | DS-1 4, DS-2 3 |
| R4 | 같은 마크 3개가 한 줄에 놓이면 그 마크의 승리다 | DS-3 1·2 |
| R5 | 9칸이 모두 차고 승리 줄이 없으면 무승부다 | DS-1 7 |
| R6 | 결과가 난 게임에는 수를 둘 수 없다 | DS-3 3 |
| R7 | 결과가 나면 스코어의 해당 항목이 정확히 1 오른다 | DS-1 8, DS-3 4 |
| R8 | 어려움 컴퓨터는 이길 수 있으면 이기고, 질 위기면 막는다 (지지 않는다) | DS-1 5, US-4 |

## ③ 인수 조건 (Given-When-Then)
- **AC-1 · R1** Given 새 게임 / When 시작하면 / Then 차례는 X
- **AC-2 · R2, R3** Given 0번 칸에 X가 있음 / When O가 0번 칸에 두려 하면 / Then 거절되고 "빈 칸에만 둘 수 있어요", 차례는 그대로 O
- **AC-3 · R3** Given X 차례 / When X가 빈 칸에 두면 / Then 차례는 O
- **AC-4 · R4** Given X가 0·1번 칸에 있음 / When X가 2번 칸에 두면 / Then 결과는 X 승리, 승리 줄은 [0,1,2]
- **AC-5 · R5** Given 승리 줄 없이 8칸이 참 / When 마지막 칸에 두면 / Then 결과는 무승부
- **AC-6 · R6** Given 결과가 난 게임 / When 수를 두려 하면 / Then 거절되고 "이미 끝난 게임이에요"
- **AC-7 · R7** Given 스코어 0/0/0 / When X 승리로 끝나면 / Then X 승리만 1
- **AC-8 · R8** Given 어려움 컴퓨터(O), O가 한 수 만에 이길 수 있음 / When 컴퓨터가 두면 / Then 이기는 칸을 고른다
- **AC-9 · R8** Given 어려움 컴퓨터(O), X가 다음 수에 이길 수 있음 / When 컴퓨터가 두면 / Then 그 칸을 막는다
- **AC-10 · R8** Given 어려움 컴퓨터 / When X가 어떤 순서로 두더라도 / Then 결과는 X 승리가 아니다

## ④ 화면 상태 (피그마에서 그릴 것)
| 화면 | 빈 상태 | 오류 상태 | 진행 상태 |
|------|---------|-----------|-----------|
| 게임 보드 | 빈 보드 + "X부터 시작해요" | 찬 칸 누름 → "빈 칸에만 둘 수 있어요" 토스트 | 상단 차례 배지 (X 코랄 / O 블루) |
| 결과 모달 | – | – | X 승리 / O 승리 / 무승부 3가지 + 승리 줄 강조 |
| 내 기록 | 0판일 때 "첫 게임을 시작해 보세요" + 시작 버튼 | – | 승/무/패 스코어 카드 |
